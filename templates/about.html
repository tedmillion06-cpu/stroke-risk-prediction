Project Overview

This project explores machine-learning approaches for predicting the stroke class from clinical and demographic information. Random Forest and XGBoost are compared using a consistent preprocessing strategy, test dataset, and evaluation framework.

Random Forest

Random Forest combines multiple decision trees to generate predictions. Its performance can be evaluated using precision, recall, F1-score, ROC-AUC, and a confusion matrix.

XGBoost

XGBoost builds boosted decision trees sequentially. Its performance is compared with Random Forest using the same evaluation data and metrics.

Project Features

  • Clinical and demographic input features
  • Random Forest and XGBoost predictions
  • Predicted stroke probability percentages
  • Model comparison and evaluation
Medical disclaimer: This application is an academic demonstration, not a clinically validated diagnostic tool. Predictions must not be used to make medical decisions.
